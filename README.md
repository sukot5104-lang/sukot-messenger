# 🚀 SUKOT MESSENGER

**پیام‌رسان آنلاین، سریع، امن و کاملاً کاربردی با آیدی اختصاصی — بدون شماره موبایل، بدون ایمیل، بدون کد پیامکی**

ساخته‌شده توسط **Sukot** ✅

---

## ✨ ویژگی‌ها

### ثبت‌نام و ورود با آیدی
- ثبت‌نام فقط با یک **آیدی اختصاصی** و رمز عبور
- بررسی یکتایی آیدی در **سرور و دیتابیس** (قید `UNIQUE` دوگانه: نمایشی + حروف کوچک)
- جلوگیری قطعی از ثبت آیدی تکراری حتی با ثبت هم‌زمان
- آیدی‌های رزروشده و نامعتبر قابل ثبت نیستند
- **حفاظت کامل برند**: هیچ‌کس نمی‌تواند آیدی شبیه `Sukot` بسازد (`su_kot`، `suk0t`، `SUKOT2` و... همه رد می‌شوند)
- بررسی زنده موجودبودن آیدی هنگام ثبت‌نام (تیک سبز / ضربدر قرمز)

### حساب رسمی پشتیبانی Sukot
- حساب **Sukot** با **تیک تأیید سبز** برای همه کاربران قابل جست‌وجوست
- کارت ویژه «پشتیبانی رسمی» در صفحه جست‌وجو همیشه نمایش داده می‌شود
- هر کاربر جدید به‌صورت خودکار یک گفت‌وگوی خوش‌آمدگویی از Sukot دریافت می‌کند
- همه پیام‌های کاربران به Sukot در صندوق ورودی حساب رسمی (مدیر) دیده می‌شود
- این حساب **قابل حذف، مسدودسازی یا تصاحب نیست**

### پیام‌رسانی واقعی آنلاین (WebSocket)
- ارسال و دریافت **لحظه‌ای** پیام با Socket.IO
- نمایش وضعیت **آنلاین / آفلاین** کاربران به‌صورت زنده
- نشانگر «**در حال نوشتن...**»
- تیک‌های وضعیت پیام: ✓ ارسال شد → ✓✓ رسید → ✓✓ بنفش (خوانده شد)
- ذخیره دائمی پیام‌ها در سرور — با بستن برنامه پیام‌ها می‌مانند
- نمایش زمان ارسال پیام‌ها با تاریخ شمسی
- لیست گفت‌وگوها با تعداد پیام خوانده‌نشده

### امنیت و مدیریت
- رمز عبور با **bcrypt** (۱۲ راند) هش می‌شود — هرگز متن ساده ذخیره نمی‌شود
- احراز هویت با **JWT** در کوکی HttpOnly
- اعتبارسنجی همه ورودی‌ها در سرور (Zod)
- **محدودسازی درخواست** (Rate Limit) برای جلوگیری از سوءاستفاده
- مسدودکردن کاربران مزاحم + گزارش تخلف
- حذف گفت‌وگو از لیست شخصی
- **حذف حساب** با تأیید رمز عبور
- کنترل دسترسی به گفت‌وگوها — هیچ‌کس پیام‌های خصوصی دیگران را نمی‌بیند

### پنل مدیریت (سطح دسترسی مستقل)
- ورود با رمز مدیریت مستقل از حساب کاربری
- آمار زنده: کل کاربران، آنلاین‌ها، پیام‌ها، گفت‌وگوها
- مدیریت کاربران: مسدودکردن / رفع مسدودی / تیک تأیید سبز / حذف و آزادسازی آیدی
- مدیریت گزارش‌های تخلف کاربران
- مدیریت **آیدی‌های رزروشده** (افزودن / حذف)
- **تعیین سیاست آیدی پس از حذف حساب**:
  - `رزرو دائمی` → آیدی هیچ‌وقت قابل ثبت مجدد نیست (امن‌تر)
  - `آزادسازی` → آیدی آزاد می‌شود و کاربر دیگری می‌تواند بگیرد
- مشاهده لاگ‌های سیستمی (ورودها، خطاها، اقدامات مدیر)

### طراحی
- تم تیره با رنگ‌های **مشکی، خاکستری و بنفش نئونی**
- طراحی واکنش‌گرا برای موبایل و دسکتاپ (نمای دوستونه مثل تلگرام وب)
- **فارسی و راست‌چین (RTL) کامل** با فونت وزیرمتن
- انیمیشن‌های روان و سبک
- PWA — قابل نصب روی **اندروید، iOS و ویندوز**

## 🧰 تکنولوژی‌ها

| بخش | تکنولوژی |
|---|---|
| فرانت‌اند | Next.js 16 (App Router) + TypeScript + Tailwind CSS 4 |
| بک‌اند | Route Handlers امن + WebSocket (Socket.IO) |
| دیتابیس | SQLite با Prisma ORM (قابل تعویض با PostgreSQL) |
| پیام‌رسانی لحظه‌ای | سرویس مستقل Socket.IO (پورت 3003) |
| احراز هویت | JWT + bcrypt + کوکی HttpOnly |
| اعتبارسنجی | Zod + قوانین سرور-side |

## 📦 ساختار جداول دیتابیس

| جدول | کارکرد |
|---|---|
| `User` | کاربران — `username` و `usernameLower` هر دو UNIQUE (جلوگیری قطعی از تکراری بودن) |
| `Conversation` | گفت‌وگوهای خصوصی دو نفره |
| `Participation` | عضویت کاربران در گفت‌وگو + زمان خواندن/دریافت + حذف از لیست شخصی |
| `Message` | پیام‌ها با زمان دقیق |
| `Block` | مسدودسازی کاربران |
| `Report` | گزارش‌های تخلف |
| `ReservedId` | آیدی‌های رزروشده که هرگز قابل ثبت نیستند |
| `Setting` | تنظیمات سیستمی (مثل سیاست حذف آیدی) |

## ⚙️ نصب و راه‌اندازی محلی

```bash
# ۱) نصب وابستگی‌ها
bun install        # یا npm install

# ۲) ساخت فایل تنظیمات
cp .env.example .env
# سپس مقادیر JWT_SECRET، ADMIN_PASSWORD، SUKOT_PASSWORD و INTERNAL_SECRET را تغییر دهید

# ۳) ساخت دیتابیس
bun run db:push    # یا npx prisma db push

# ۴) ساخت حساب رسمی Sukot و آیدی‌های رزروشده
bun run scripts/seed.ts

# ۵) اجرای سرویس پیام‌رسانی لحظه‌ای (ترمینال جداگانه)
cd mini-services/chat-service && bun run dev

# ۶) اجرای برنامه (ترمینال اصلی)
bun run dev        # یا npm run dev
```

سپس `http://localhost:3000` را باز کنید.

> **حساب رسمی بعد از seed:** آیدی `Sukot` با رمزی که در `SUKOT_PASSWORD` گذاشتید.
> **پنل مدیریت:** دکمه سپر در بالای لیست گفت‌وگوها یا مسیر برنامه ← «پنل مدیریت» با رمز `ADMIN_PASSWORD`.

## ☁️ استقرار رایگان (Free Hosting)

### معماری
برنامه دو بخش دارد که هر دو باید اجرا شوند:
1. **وب اپلیکیشن Next.js** (پورت 3000) — شامل APIها و رابط کاربری
2. **سرویس WebSocket** (پورت 3003) — پیام‌رسانی لحظه‌ای

### گزینه پیشنهادی: Railway / Render (رایگان)
هر دو سرویس WebSocket را پشتیبانی می‌کنند و HTTPS خودکار دارند:

1. مخزن را به GitHub خود Push کنید
2. در Railway/Render یک سرویس از مخزن بسازید
3. متغیرهای محیطی فایل `.env.example` را تنظیم کنید (`DATABASE_URL` را به یک **PostgreSQL رایگان** مثل [Neon](https://neon.tech) یا [Supabase](https://supabase.com) وصل کنید — کافی است `provider` در `prisma/schema.prisma` را `"postgresql"` کنید)
4. دستور اجرا:
   - وب: `bun run dev` (توسعه) یا `bun run build && bun run start` (پروداکشن)
   - چت‌سرویس: `cd mini-services/chat-service && bun run dev`
   - برای یک دامنه واحد، از Caddy/Nginx به‌عنوان reverse proxy استفاده کنید (نمونه `Caddyfile` در مخزن هست)

### محدودیت‌های طرح رایگان
- **Render**: بعد از ۱۵ دقیقه بی‌کاری سرویس می‌خوابد (اولین پیام کند می‌شود) — دیتای فایل در redeploy پاک می‌شود؛ برای دیتای پایدار PostgreSQL رایگان بگیرید
- **Railway**: سهمیه محدود ماهانه؛ برای شروع کافی است
- **Neon/Supabase**: ۰٫۵–۱ گیگ دیتابیس رایگان — برای هزاران کاربر کافی است

### روش ارتقا در صورت افزایش کاربران
- دیتابیس: Neon Pro یا Supabase Pro (چند دلار در ماه)
- سرور: Railway Pro یا VPS ارزان (WebSocket اختصاصی)
- لایه کش: Redis برای presence و rate-limit چند نمونه‌ای

## 📱 نصب برنامه (Android / iOS / Windows)

برنامه **PWA** است؛ بدون نصب هم در مرورگر کامل کار می‌کند، اما می‌توانید آن را مثل اپ واقعی نصب کنید:

### اندروید
1. سایت را با **Chrome** باز کنید
2. منوی سه‌نقطه ← **«Add to Home screen»** (یا دکمه نصب داخل برنامه در بخش پروفایل)
3. آیکون SUKOT مثل اپ مستقل نصب می‌شود

**ساخت فایل APK واقعی:** پوشه `installers/android` یک پروژه اندروید کامل است + اکشن GitHub (`.github/workflows/build-android.yml`) که با هر Push، فایل **APK** می‌سازد و در بخش Actions قابل دانلود است. فقط آدرس سایت را در `installers/android/app/src/main/res/values/strings.xml` جایگزین کنید.

### iOS
1. سایت را با **Safari** باز کنید
2. دکمه اشتراک‌گذاری ← **«Add to Home Screen»**
3. اپ با تمام‌صفحه و آیکون اختصاصی اجرا می‌شود
(ساخت فایل IPA به اپل دولوپر اکانت و Xcode نیاز دارد — قالب پروژه در `installers/ios` آماده است)

### ویندوز
1. سایت را با **Edge** یا **Chrome** باز کنید
2. منوی سه‌نقطه ← **«Apps» ← «Install SUKOT MESSENGER»**
3. اپ با پنجره مستقل و آیکون در استارت‌منو نصب می‌شود

**ساخت فایل EXE واقعی:** پوشه `installers/windows` یک پروژه Electron آماده است + اکشن GitHub (`.github/workflows/build-windows.yml`) که فایل **EXE نصب‌کننده** می‌سازد و در Actions قابل دانلود است. فقط آدرس سایت را در `installers/windows/main.js` جایگزین کنید.

## 🛡️ نکات امنیتی پیاده‌سازی‌شده

- یکتایی آیدی با **دو قید UNIQUE** در دیتابیس (مستقل از UI)
- رمز عبور هش‌شده با bcrypt-12؛ مقایسه امن
- کوکی‌های HttpOnly + SameSite=Lax + Secure (روی HTTPS)
- Rate limit روی: ثبت‌نام، ورود، جست‌وجو، ارسال پیام، گزارش، ورود مدیر
- بررسی عضویت در گفت‌وگو قبل از هر عملیات پیام
- اعمال مسدودی دوطرفه در سطح سرور
- ورود مدیر **کاملاً جدا** از کاربران (مخفی‌کردن دکمه امنیت نیست!)
- محافظت برند Sukot در سطح الگو (تشخیص suk0t، su.kot، ۵ukot و...)
- لاگ سیستمی برای ورودها و اقدامات حساس
