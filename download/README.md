# 📦 فایل‌های نصب SUKOT MESSENGER

| فایل | پلتفرم | راهنما |
|---|---|---|
| `SUKOT-Messenger-Android.apk` | اندروید | دانلود → باز کردن → اجازه نصب از منابع ناشناس → نصب |
| `SUKOT-Messenger-Setup-Windows.exe` | ویندوز (نصب‌کننده) | اجرا → Next → نصب (آیکون در استارت‌منو و دسکتاپ) |
| `SUKOT-Messenger-Portable-Windows.exe` | ویندوز (بدون نصب) | مستقیم اجرا کنید |

⚠️ در فایل‌های نصب‌کننده فعلی آدرس سایت به‌صورت پیش‌فرض است. پس از استقرار سایت خود، آدرس را در `installers/` تغییر دهید — GitHub Actions دوباره فایل‌ها را می‌سازد.

📱 **iOS:** نصب با Safari ← دکمه اشتراک ← Add to Home Screen (راهنمای کامل در مخزن: installers/ios/README.md)
